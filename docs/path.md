# Путь — карта кода

Один путь изучения на всё приложение. Этап — тема (или её часть до 10 слов);
у этапа дорожки-навыки: перевод, потом письмо. Решения и правила — в начале
`src/utils/path/stages.ts`.

| Файл | Что внутри |
|---|---|
| `src/content/path/themes.ts` | темы по уровням HSK (правятся руками; проверка — `node scripts/check-path-themes.mjs`). Пока только HSK 1, остальные уровни — по частоте |
| `src/utils/path/stages.ts` | этапы всех разделов подряд, дорожки (`TRACKS`), прогресс: пройдено (у всех слов ≥1 точки) / освоено (3 точки), текущий этап, «Продолжить» |
| `src/hooks/usePath.ts` | прогресс пути из стора и запуск тренировки дорожки (ставит `returnTo`, чтобы итоги вернули на путь) |
| `src/app/(tabs)/games/path/index.tsx` | карта: тропинка, вехи HSK, «Начать / Продолжить» |
| `src/app/(tabs)/games/path/stage.tsx` | экран этапа: дорожки с «Тренировать», «Продолжить», сетка слов с двумя строками точек |
| `src/components/path/PathNode.tsx` | точка на карте: кольца дорожек, подпись, кусок тропинки, пульс, печать «освоен» |
| `src/components/path/PathWordGrid.tsx` | сетка слов этапа |
| `src/app/(tabs)/games/writing/path.tsx` | тренировка письма по этапу |

Тренировка перевода этапа — обычный экран карточек с `setId = "path:1:0"`
(см. `utils/flashcards/source.ts`).

Новый навык: добавить запись в `TRACKS`, правило точек в `getTrackDots`,
слова дорожки в `trackWords` и запуск в `usePath.startTraining`.
