# Путь — карта кода

Один путь изучения на всё приложение. Этап — тема (или её часть до 10 слов);
у этапа дорожки-навыки: перевод, потом письмо. Решения и правила — в начале
`src/utils/path/stages.ts`.

| Файл | Что внутри |
|---|---|
| `src/content/path/themes.ts` | темы по уровням HSK (правятся руками; проверка — `node scripts/check-path-themes.mjs`). Темы есть у всех уровней HSK 1–4 |
| `src/utils/path/stages.ts` | этапы всех разделов подряд, дорожки (`TRACKS`), прогресс: пройдено (у всех слов ≥1 точки) / освоено (3 точки), текущий этап, «Продолжить» |
| `src/hooks/usePath.ts` | прогресс пути из стора и запуск тренировки дорожки (ставит `returnTo`, чтобы итоги вернули на путь) |
| `src/app/(tabs)/games/path/index.tsx` | карта: тропинка, вехи HSK, выбор раздела «HSK 1 ▾», «Начать / Продолжить» |
| `src/app/(tabs)/games/path/stage.tsx` | экран этапа: дорожки с «Тренировать», «Продолжить», сетка слов с двумя строками точек |
| `src/components/path/PathNode.tsx` | точка на карте: одно кольцо общего прогресса, название и навыки иконками (книга — перевод, карандаш — письмо), кусок тропинки, пульс и значок панды у текущего, галочка — только «освоен» (3 точки у каждого слова в обоих навыках); непройденная тропинка — зелёный пунктир |
| `src/components/path/PathWordGrid.tsx` | сетка слов этапа |
| `src/components/path/ScrollingBackground.tsx` | повторяющийся фон-пейзаж с параллаксом (три плитки `assets/images/backgrounds/path-1..3.jpg` — одна бесшовная петля, разрезанная на части) |
| `src/app/(tabs)/games/writing/path.tsx` | тренировка письма по этапу |

Тренировка перевода этапа — обычный экран карточек с `setId = "path:1:0"`
(см. `utils/flashcards/source.ts`).

## Разделы

Раздел = уровень HSK (`getPathSections` в `stages.ts`). Других делений нет: темы — это
сами этапы. Между разделами на тропинке — веха «HSK 2». В шапке экрана «HSK N ▾» показывает
раздел на экране; тап — шторка с разделами и прогрессом, выбор прокручивает карту к разделу.

Новый навык: добавить запись в `TRACKS`, правило точек в `getTrackDots`,
слова дорожки в `trackWords` и запуск в `usePath.startTraining`.

## Знакомство и переход к письму

- Новое слово (ни одного ответа по переводу) в тренировке перевода сначала показывается
  карточкой `src/components/game/WordIntroCard.tsx`: звук, пиньинь, перевод и «Из чего
  состоит» (части знака; если часть — слово словаря, рядом её перевод). Потом — вопрос.
- Экран итогов: если тренировка перевода шла по этапу пути (`gameStore.lastSourceId`)
  и перевод этапа пройден, а письмо нет, — кнопка «Перевод пройден — попробовать написать».
