# Написание иероглифов — карта кода

Где что лежит в режиме «Написание». Правило: **экран → хук → utils**.
Экран только раскладывает компоненты, хук ведёт состояние, `utils/writing` — чистая логика.

Экраны лежат прямо в `app/`, как у остальных тренировок. Исключение — урок:
его открывают несколько маршрутов, поэтому он в `components/writing/lesson/`
(всё, что лежит в `app/`, expo-router делает отдельной страницей).

## Маршруты — `src/app/(tabs)/games/writing/`

Своего главного экрана у письма больше нет: уроки запускают «Словарь»
(`src/app/(tabs)/vocabulary.tsx`) и путь (`src/app/(tabs)/games/path/`).

| Файл | Что открывает |
|---|---|
| `free.tsx` | урок по одному слову (быстрый или полный) — «Написать» в панели слова |
| `path.tsx` | урок по списку слов: этап пути, избранное, «Другие слова» (`?source=` или `?stage=`) |
| `review.tsx` | урок по «Повторению» |
| `set.tsx` | урок по своему набору |

«Назад» и «Продолжить» в итогах ведут туда, откуда урок запустили (`gameStore.returnTo`),
по умолчанию — в «Словарь».

## Хуки — `src/hooks/writing/`

- `useWritingLesson` — ход урока: слова → этапы → ячейки → черты, подсказки, работа над ошибками.
- `useCanvasSize` — размер большого холста под экран.

## Логика — `src/utils/writing/`

| Файл | Что внутри |
|---|---|
| `words.ts` | какие слова можно писать (пул), разделы HSK, точки письма, иероглифы внутри слов (`char:么`), `syllableOf` |
| `steps.ts` (пока остаётся) | ступени: по темам из `content/path/themes.ts` (если у уровня есть темы) или по частоте по 10 слов; названия ступеней, прогресс |
| `plans.ts` | планы уроков: свободный, «Повторение», работа над ошибками, классический |
| `stages.ts` | этапы урока для слова: части → иероглиф → слово, форматы full / light / quick |
| `strokeCheck.ts` | проверка одной черты |
| `lessonResults.ts` | конец урока: точки, данные для итогов и панды, награда |
| `labels.ts` | «5 слов», «через 9 ч» |

## Компоненты — `src/components/writing/`

- `canvas/` — всё, что рисует иероглиф: `WritingCanvas` (письмо пальцем), `DemoCanvas` (показ порядка черт), `HanziView` (маленькое превью), `hanziSvg` (цвета холста, сетка «тянь цзы гэ», линия).
- `lesson/WritingLessonScreen` — экран урока: показ → контур → по памяти, сравнение в конце слова.
- `lesson/LessonParts` — общие куски урока: шапка, слово, «Напиши …», написанные иероглифы, «Эталон / Твоё», кнопки.
- `home/` — остатки бывшего главного экрана, которыми пользуется «Словарь»: `ReviewCard`, `WritingDots`.
- `results/` — итоги: `WritingResultsList` (на экране статистики).

## Данные

- `src/content/path/themes.ts` — темы пути (порядок тем и слова в них, правится руками; проверка — `node scripts/check-path-themes.mjs`). Пока только HSK 1.

- `src/content/writing/hanziData.json` — черты иероглифов, собирается `scripts/build-hanzi-data.mjs`.
- Прогресс письма, «Повторение» — в `src/store/wordProgressStore.ts`.
