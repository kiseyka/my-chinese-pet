# Написание иероглифов — карта кода

Где что лежит в режиме «Написание». Правило: **маршрут → экран → хук → utils**.
Экран только раскладывает компоненты, хук ведёт состояние, `utils/writing` — чистая логика.

## Маршруты — `src/app/(tabs)/games/writing/`

| Файл | Что открывает |
|---|---|
| `sets.tsx` | главный экран «Написание» (`WritingHomeScreen`) |
| `free.tsx` | урок по одному слову из сетки (быстрый или полный) |
| `review.tsx` | урок по списку «Повторение» |
| `exam.tsx` | экзамен по готовым словам |
| `classic.tsx` | старая «классическая» тренировка по разделу (сейчас никуда не ведёт) |

## Экраны — `src/screens/writing/`

- `WritingHomeScreen` — сетка ступеней, поиск, входы в «Экзамен» и «Повторение», окна.
- `WritingLessonScreen` — урок: показ → контур → по памяти, сравнение в конце слова.
- `WritingExamScreen` — экзамен: только по памяти, вердикт, итоги.

## Хуки — `src/hooks/writing/`

- `useWritingHome` — всё состояние главного экрана: прогресс, очередь экзаменов, открытые окна, переходы.
- `useWritingLesson` — ход урока: слова → этапы → ячейки → черты, подсказки, работа над ошибками.
- `useWritingExam` — ход экзамена: ошибки на слово, «черта в стороне», вердикт.
- `useCanvasSize` — размер большого холста под экран.

## Логика — `src/utils/writing/`

| Файл | Что внутри |
|---|---|
| `words.ts` | какие слова можно писать (пул), разделы HSK, точки письма, иероглифы внутри слов (`char:么`), `syllableOf` |
| `steps.ts` | порядок изучения, деление на ступени по 10 слов, прогресс ступеней |
| `plans.ts` | планы уроков: свободный, «Повторение», работа над ошибками, классический |
| `stages.ts` | этапы урока для слова: части → иероглиф → слово, форматы full / light / quick |
| `strokeCheck.ts` | проверка одной черты |
| `lessonResults.ts` | конец урока: точки, данные для итогов и панды, награда |
| `search.ts` | поиск по иероглифу, пиньиню без тонов и переводу |
| `labels.ts` | «5 слов», «через 9 ч» |

## Компоненты — `src/components/writing/`

- `canvas/` — всё, что рисует иероглиф: `WritingCanvas` (письмо пальцем), `DemoCanvas` (показ порядка черт), `HanziView` (маленькое превью), `hanziSvg` (цвета холста, сетка «тянь цзы гэ», линия).
- `lesson/LessonParts` — общие куски урока и экзамена: шапка, слово, «Напиши …», написанные иероглифы, «Эталон / Твоё», кнопки.
- `home/` — главный экран: `WordGrid` (сетка слов), `WritingDots`, `StepCard`, `ReviewCard`, `ExamEntryCard`, `LevelSections`.
- `modals/` — нижние окна: `PracticeChoiceModal` (окно слова, его блоки — в `PracticeChoiceParts`), `ExamModal`, `ReviewModal`.
- `results/` — итоги: `WritingResultsList` (на экране статистики), `ExamResultsList`.
- `SealMark` — печать 印, общая для всех.

## Данные

- `src/content/writing/hanziData.json` — черты иероглифов, собирается `scripts/build-hanzi-data.mjs`.
- Прогресс письма, «Повторение» и экзамены — в `src/store/wordProgressStore.ts`.
