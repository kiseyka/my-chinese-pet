# Панда — мысли (облачко «…»)

Панда сама не заговаривает. Когда ей есть что сказать, над головой появляется облачко
«…». Тап по панде — реплика (тап и есть «да, давай», отдельного «Не сейчас» нет).
Смахнул панель или тапнул мимо — мысль остаётся, облачко возвращается. Непрочитанная
мысль живёт до конца дня, потом тихо пропадает (фраза не считается рассказанной).

Окно фразы — маленький диалог: шапка (панда и имя; озвучка и глазик пиньиня), фраза
(скрытый пиньинь только прозрачный — фраза не прыгает), плашка «Показать перевод»,
которая на месте превращается в перевод, пояснение «Почему так говорят?» сразу
карточкой. Панда сразу произносит фразу (если звук не выключен в настройках).
Тап по слову (во фразе, в реакции панды, по выражению в пояснении) — тултип: пиньинь,
перевод, «Повторение», «Этап». В пояснении иероглифы подряд — одно выражение
(送钟 целиком): перевод из `note.terms`, затем из самой фразы, затем из словаря.
Варианты ответа: до 3 иероглифов — сеткой 2×2, длиннее — списком; пиньинь над
иероглифами (глазик), перевод под ними (文A).

У вопросов (`replies`) — варианты ответа по-китайски. Выбранный ответ встаёт справа,
как сообщение пользователя, под ним реакция панды; «Понятно» — после ответа. Ответ
запоминается (`pandaStore.answers`) и открывает фразы с `requires` — панда помнит:
«ты любишь зелёный — мой цветок тоже зелёный». Свой ответ текстом не вводится:
проверить свободный ответ по-китайски без модели нельзя.

## Виды мыслей

- **Фраза** — короткая фраза на китайском из слов, которые пользователь уже изучает
  (у каждого слова хотя бы 1 точка перевода или письма). Слова разбираются тапом
  (пиньинь, перевод, озвучка), «Покажи перевод», «Понятно» → фраза уходит в коллекцию
  «Фразы панды» в профиле. Рассказанная фраза больше не предлагается.
  У разговорных фраз есть пояснение `note` — «Почему так говорят?» (откуда фраза,
  когда её говорят): ссылка под фразой в реплике и в профиле.
- **Загадка** — по слову из «Повторения», только если сегодня ещё не было тренировки.
  - *выбрать*: перевод → три похожих иероглифа (подбор как на экзамене по переводу);
  - *написать*: слово по памяти на отдельном экране (если его уже писали). Мягко:
    черта в стороне ставится на место, после двух ошибок на черте — её контур.
    В конце — эталон и твоё написание (тап — в галерею).
  - Точек не даёт и не отнимает.
- Позже: **коробка с подарком** за вехи пути (растения, сувениры) и **праздники**.

## Правила, чтобы не надоедало

- Одна мысль за раз.
- Каждый вид — не чаще раза в день (сейчас видов два → не больше двух мыслей в день).
- Между мыслями пауза 2 часа: облачко не встречает после каждой тренировки.
- Мысль, которую не открыли до конца дня, пропадает.
- Фраза только к месту: поле `when` — время суток (утро 5–11, день 11–17, вечер 17–22,
  ночь 22–5) и время года. Облачко с фразой, время которой прошло, тихо пропадает.
- Последние 5 показанных фраз (даже недочитанные) не предлагаются, если есть другие.
- Русские переводы учитывают род из профиля (он / она, тап по имени):
  `{пил|пила}`, без выбора — «пил(а)» (`utils/gender.ts`).
- Слово загадки не повторяется среди последних 8.

## Игра по тапу (без облачка)

Облачко — когда панда начинает сама (редко, 1–2 раза в день). Тап по панде **без**
облачка — когда начинаешь ты: панда предлагает поиграть (`utils/panda/play.ts`,
`PandaPlaySheet`). Не больше **15 игр за 3 часа** (`PLAYS_PER_WINDOW`, `PLAY_WINDOW_MS`), потом «я немного устала, приходи через …».

- **Угадай слово** — по переводу выбрать иероглиф из трёх, прямо в панели. Верно — +1 опыт.
- **Послушай и угадай** — панда произносит слово, выбрать иероглиф из трёх. Верно — +1 опыт.
- **Допиши черту** — иероглиф нарисован без одной черты, её нужно дописать
  (`/panda-riddle?mode=stroke`). Любые начатые слова, которые можно писать. +1 опыт.
- **Напиши слово** — по памяти на экране `/panda-riddle?source=play`, только слова,
  которые уже писали. +1 опыт, без ошибок — +2.
- Слова: начатые (хотя бы 1 точка), без «Повторения»; начатых нет — первые 2 этапа пути. Для «угадай» и «послушай» — до 2 иероглифов и только если нашлись 2 похожих варианта. Последние 8 не повторяются. Загадка в облачке берёт слова так же.
- Любая доигранная игра — привязанность +1. Точки слов не меняются.
- Слов ещё нет — «давай сначала выучим пару слов» и кнопка «К пути».

Награды (решено 23 октября): **только опыт**, как в тренировках — 1 за верный ответ,
2 за слово, написанное без ошибок. Монет нет: за целую тренировку их максимум 5.
Отдельной шкалы отношений нет — чтобы не путать, «отношения с пандой» = уровень опыта.
Привязанность (+1 за игру) остаётся внутренним счётчиком на будущее, на экране не видна.

## Rive

Слой `Layer_thought` в State Machine 1 файла `assets/motion/panda.riv`:

| Вход | Тип | Что делает |
|---|---|---|
| `hasThought` | bool | idle → waiting_look (лучики один раз) → waiting; false → idle |
| `look` | trigger | лучики ещё раз — при возвращении на экран, пока облачко висит |
| `tap` | trigger | сжатие и свечение, затем idle |

После тапа `hasThought` гасится через 400 мс — после анимации тапа.
Нет слоя в файле — ничего не ломается, облачка просто не видно
(или включи `THOUGHT_CLOUD = "stub"` в `PandaScene.tsx`).

## Проверка на телефоне

`TEST_MODE = true` в `src/utils/panda/thoughts.ts` — без паузы, дневных лимитов и условия
«сегодня не было тренировки»: новая мысль при каждом входе на экран панды.

Rive: в файле панды не должно быть растровых картинок с mesh — рендер Rive на Android
на них иногда падает (SIGSEGV в `rive::Mesh::draw`), приложение закрывается без ошибок.
