# Панда — мысли (облачко «…»)

Панда сама не заговаривает. Когда ей есть что сказать, над головой появляется облачко
«…». Тап по панде — реплика (тап и есть «да, давай», отдельного «Не сейчас» нет).
Смахнул панель или тапнул мимо — мысль остаётся, облачко возвращается. Непрочитанная
мысль живёт до конца дня, потом тихо пропадает (фраза не считается рассказанной).

Окно фразы — маленький диалог: шапка (панда и имя; озвучка и глазик пиньиня), фраза
(скрытый пиньинь только прозрачный — фраза не прыгает), плашка «Показать перевод»,
которая на месте превращается в перевод, пояснение «Почему так говорят?» сразу
карточкой. Тап по слову (во фразе, в реакции панды, по иероглифу в пояснении) —
тултип: пиньинь, перевод, «Повторение», «Этап».

У вопросов (`replies`) — варианты ответа по-китайски. Выбранный ответ встаёт справа,
как сообщение пользователя, под ним реакция панды; «Понятно» — после ответа. Ответ
запоминается (`pandaStore.answers`) и открывает фразы с `requires` — панда помнит:
«ты любишь зелёный — мой цветок тоже зелёный». Свой ответ текстом не вводится:
проверить свободный ответ по-китайски без модели нельзя.

## Виды мыслей

- **Фраза** — короткая фраза на китайском из слов, которые пользователь уже изучает
  (у каждого слова хотя бы 1 точка перевода или письма). Слова разбираются тапом
  (пиньинь, перевод, озвучка), «Покажи перевод», «Понятно» → фраза уходит в коллекцию
  «Фразы панды» в профиле. Рассказанная фраза больше не предлагается.
  У разговорных фраз есть пояснение `note` — «Почему так говорят?» (откуда фраза,
  когда её говорят): ссылка под фразой в реплике и в профиле.
- **Загадка** — по слову из «Повторения», только если сегодня ещё не было тренировки.
  - *выбрать*: перевод → три похожих иероглифа (подбор как на экзамене по переводу);
  - *написать*: слово по памяти на отдельном экране (если его уже писали). Мягко:
    черта в стороне ставится на место, после двух ошибок на черте — её контур.
    В конце — эталон и твоё написание (тап — в галерею).
  - Точек не даёт и не отнимает.
- Позже: **коробка с подарком** за вехи пути (растения, сувениры) и **праздники**.

## Правила, чтобы не надоедало

- Одна мысль за раз.
- Каждый вид — не чаще раза в день (сейчас видов два → не больше двух мыслей в день).
- Между мыслями пауза 2 часа: облачко не встречает после каждой тренировки.
- Мысль, которую не открыли до конца дня, пропадает.
- Слово загадки не повторяется среди последних 8.

## Rive

Слой `Layer_thought` в State Machine 1 файла `assets/motion/panda.riv`:

| Вход | Тип | Что делает |
|---|---|---|
| `hasThought` | bool | idle → waiting_look (лучики один раз) → waiting; false → idle |
| `look` | trigger | лучики ещё раз — при возвращении на экран, пока облачко висит |
| `tap` | trigger | сжатие и свечение, затем idle |

После тапа `hasThought` гасится через 400 мс — после анимации тапа.
Нет слоя в файле — ничего не ломается, облачка просто не видно
(или включи `THOUGHT_CLOUD = "stub"` в `PandaScene.tsx`).

## Проверка на телефоне

В режиме разработки (dev-клиент) под шапкой экрана панды есть кнопки 🧪:
«Фраза», «Выбрать», «Написать» — сразу облачко с мыслью этого вида, без правил и лимитов
(фраза или слово берутся любые, если подходящих по правилам нет); «Сброс» — убрать
облачко и сбросить паузу, дневной лимит и «Не сейчас». В preview- и релизной сборке
кнопок нет. Выключить — `SHOW_THOUGHT_TEST_PANEL` в `ThoughtTestPanel.tsx`.
