# Слова дня — карта кода

Занятие без выбора на экране панды: карточка «Сегодня» с двумя строками —
«Слова» (перевод) и «Письмо». Путь и «Словарь» смотреть не нужно.

## Правила

- **Два независимых пула**: перевод и письмо. Письмо не тормозит перевод: можно
  знать HSK 3 и писать только HSK 1.
- **Новых в день** — отдельно для перевода (1–5) и письма (1–3). Спрашиваем при
  первом заходе на панду; потом — тап по «Сегодня». Новые числа — со следующего дня.
- **Добор** раз в день: `min(N, 2N − в пуле)`. Пул не больше 2N: застрявшее слово
  занимает один слот, а не всю очередь.
- **Откуда слова**: путь по порядку этапов. Перевод — слова без точек перевода,
  письмо — слова, которые можно писать, без точек письма.
- **Одна точка в день**: тренировка слов дня берёт только слова, с которыми сегодня
  не занимались. Тренировка на пути или в «Словаре» тоже отмечает слово пула
  сделанным на сегодня.
- **Перевод, выход из пула**: 3 точки → на следующий день (или позже) «Помнишь?»:
  «знаю» — уходит; «сомневаюсь» / «не знаю» — остаётся и идёт в тренировку.
  Точек «Помнишь?» не даёт, в «Повторение» не кладёт.
- **Письмо**: перед уроком «Знаешь, как пишется?» (перевод и пиньинь, без иероглифа).
  «Знаю» — сразу по памяти: без подсказок — **все 3 точки** и слово уходит из пула;
  с подсказками — в конце работа над ошибками. «Не знаю» — обычный урок
  (новое — полный цикл, начатое — быстрый). Слово с 3 точками письма уходит
  из пула, где бы его ни написали.

## Код

| Файл | Что внутри |
|---|---|
| `src/store/dailyStore.ts` | хранение: «новых в день», день добора, пулы (`addedDay`, `doneDay`) |
| `src/utils/daily.ts` | добор и уборка (`syncDaily`), план на сегодня (`getDailyPlan`), слова тренировок, `markDailyDone` |
| `src/hooks/useDaily.ts` | для экрана панды: `syncDaily` при заходе, планы, запуск, сохранение настроек |
| `src/components/daily/DailyCard.tsx` | карточка «Сегодня» |
| `src/components/daily/DailySetupSheet.tsx` | «Сколько новых слов в день?» |
| `src/app/(tabs)/games/daily/reading.tsx` | «Помнишь?», затем тренировка перевода `daily:reading` |
| `src/app/(tabs)/games/daily/writing.tsx` | «Знаешь, как пишется?», затем урок письма (`createDailyPlan`) |

Тренировка перевода слов дня — обычный экран карточек с `setId = "daily:reading"`
(`utils/flashcards/source.ts`); слов может быть меньше 4 — варианты добираются из базы.
Формат урока письма `memory` — сразу целиком по памяти (`utils/writing/stages.ts`),
флаг `memoryCheck` у задания даёт 3 точки (`utils/writing/lessonResults.ts`).
