## Что считается новостью

- **Раздел HSK пройден** — все этапы раздела пройдены.
- **Этап освоен** — печать 印 (про «пройден» для этого же этапа не повторяем).
- **Этап пройден** — с названием следующего этапа (или «последний этап пути»).
- **Слово изучено полностью** — сданы все его экзамены.
- **Экзамен** по переводу или письму: сколько слов сдано; если ни одного — мягкая поддержка.

Одна новость — одна фраза. Несколько — список «Вот что у нас нового:», важное сверху,
повторы склеены (три экзамена по письму → одна строка с суммой), не больше 5 строк,
дальше — «…и ещё немного хорошего!».

| Файл | Что внутри |

| `src/utils/panda/milestones.ts` | вехи пути: снимок того, что панда уже отметила (`pandaStore.milestones`), и сравнение с текущим состоянием — каждая веха считается один раз |

| `src/hooks/panda/usePandaNews.ts` | значок, открытие реплики, «Ура!» |
| `src/i18n/locales/{ru,en}/panda/news.json` | тексты (пространство имён `panda`), с формами множественного числа |
