# Профиль — карта кода

Сводка из реальных данных: дни с пандой, слова по навыкам, путь, активность.
Вход — тап по «Уровень / Опыт» на экране панды.

| Файл | Что внутри |
|---|---|
| `src/store/activityStore.ts` | журнал занятий: `days["2026-10-18"] = { trainings, answers }`. День появляется при входе в приложение (`markVisit`), тренировка — при каждом экране итогов и экзамене (`recordTraining`). Дни не сбрасываются |
| `src/hooks/useDailyVisit.ts` | отмечает день при запуске и при возврате в приложение; ждёт загрузки журнала с диска; один раз дополняет журнал днями из старого прогресса (`lastAnsweredAt`, сданные экзамены, наборы) |
| `src/utils/activity.ts` | ключ дня (местное время), серия подряд, лучшая серия, сетка недель |
| `src/utils/finishTraining.ts` | `finishTraining({ answers })` и `logTraining(answers)` — запись в журнал (экзамены зовут `logTraining` сами) |
| `src/utils/profile/stats.ts` | сводка: начато / освоено / экзамены по переводу и письму, «полностью изучено» (сданы все экзамены слова — как золотистая ячейка), этапы пути, текущий HSK, разбивка по уровням |
| `src/app/(tabs)/profile.tsx` | экран: дни, «Слова», «Путь», «Активность» (12 недель) |

Правила:

- **Дней с пандой** — все дни, когда открывали приложение. Только растёт.
- **Подряд** — дни подряд до сегодня (или до вчера, если сегодня ещё не заходили). Показывается мелко, без напоминаний.
- **Полностью изучено** — сдан экзамен по переводу и, если слово можно писать, по письму.
- Считаются все слова словаря, включая «Другие слова».
- Новая тренировка: передать `answers` в `finishTraining` — и она попадёт в журнал.
