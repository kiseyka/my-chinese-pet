# Профиль — карта кода

Сверху вниз: стрелка «назад» и аватар в одной строке, имя и уровень; блок из 4 чисел
(дни занятий → календарь, опыт, изученные слова → их список, текущий этап → экран этапа);
галерея написаний; политика конфиденциальности и лицензии.
Вход — круглая кнопка слева в шапке экрана панды.

| Файл | Что внутри |
|---|---|
| `src/store/activityStore.ts` | журнал занятий: `days["2026-10-18"] = { trainings, answers }`. День появляется только с тренировкой (`recordTraining`). Дни не сбрасываются |
| `src/hooks/useActivityBackfill.ts` | один раз дополняет журнал днями из старого прогресса (`lastAnsweredAt`, наборы); ждёт загрузки сторов с диска |
| `src/utils/activity.ts` | ключ дня (местное время), серия подряд, лучшая серия, сетка недель |
| `src/utils/finishTraining.ts` | `finishTraining({ answers })` и `logTraining(answers)` — запись в журнал |
| `src/utils/profile/stats.ts` | сводка: начато / освоено по переводу и письму, «изучено» (слова в «Изученном»), этапы пути, текущий HSK, разбивка по уровням |
| `src/store/profileStore.ts` | имя пользователя (задаётся тапом по имени в профиле, `NameModal`) |
| `src/app/(tabs)/profile.tsx` | экран: шапка, блок из 4 чисел (с панелями календаря и изученных слов), галерея, документы |
| `src/components/profile/StudyCalendar.tsx` | календарь по месяцам: кружок — день занятий, сегодня в рамке |
| `src/constants/legal.ts` | ссылка на политику (`PRIVACY_POLICY_URL`, пока null — заглушка) и список лицензий |
| `src/app/(tabs)/licenses.tsx` | экран «Лицензии»: источник, что взято, лицензия, тап — страница источника |
| `src/store/galleryStore.ts` | галерея: лучшее написание каждого иероглифа (`items[hanzi]`), новое заменяет старое |
| `src/components/writing/gallery/` | `SavableHanzi` — превью с значком на экранах итогов урока; `GallerySaveDialog` — «Сохранить / Заменить» (старое рядом с новым) |
| `src/components/profile/ProfileGallery.tsx` | сетка галереи в профиле; окно: «Переписать» (быстрая тренировка, вернёт в профиль) и «Удалить» |

Правила:

- **Дней занятий** — дни, в которые была хотя бы одна тренировка. Просто открыть приложение мало. Только растёт.
- Серия подряд и сетка недель есть в `utils/activity.ts`, но на экране не показываются.
- В галерею попадает только то, что пользователь сохранил сам: тап по своему написанию на экране итогов урока.
- **Изучено** — сколько слов в «Изученном» (см. `docs/dictionary.md`); тап — список.
- Считаются все слова словаря, включая «Другие слова».
- Новая тренировка: передать `answers` в `finishTraining` — и она попадёт в журнал.
