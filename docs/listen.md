# «Слушай и повторяй» — карта кода

Урок на слух: ничего не нужно нажимать. Звучит китайское слово, (перевод вслух),
пауза — повтори вслух, слово ещё раз. Два круга: второй — вперемешку, без перевода.
Экран телефона можно выключить, урок продолжится. Вход — «Тренировки».

## Озвучка

- **Китайский** — заранее сгенерированные mp3, голос Kokoro v1.0 `zf_xiaoyi`
  (Apache 2.0, офлайн). Сейчас озвучен HSK 1 (307 слов, ~1,3 МБ).
- **Перевод** — системный голос телефона (`expo-speech`, ru-RU / en-US по языку
  интерфейса). Включается переключателем «Перевод вслух» (settingsStore).

### Озвучить ещё слова

```bash
pip install sherpa-onnx soundfile numpy        # и ffmpeg в PATH
# модель ~350 МБ, в репозиторий не кладём:
# https://github.com/k2-fsa/sherpa-onnx/releases/download/tts-models/kokoro-multi-lang-v1_0.tar.bz2
npx tsx scripts/tts/export_words.ts 2 > /tmp/hsk2.json
python3 scripts/tts/generate_zh.py --words /tmp/hsk2.json --model ~/tts/kokoro-multi-lang-v1_0
```

Скрипт дописывает файлы в `assets/audio/zh/` и пересобирает манифест
`src/content/audio/zhAudio.ts` (руками не править). Готовые файлы не трогает,
`--force` — перегенерировать.

Нейтральный тон: в словаре Kokoro его нет (谢谢 звучало бы xièxiè, 东西 — dōngxī).
Для слов с нейтральным слогом в нашем пиньине скрипт строит своё произношение:
звуки из словаря модели, тоны из пиньиня, плюс правила 不 и 一.

## Код

| Файл | Что внутри |
|---|---|
| `src/app/(tabs)/games/listen.tsx` | экран: выбор слов и перевода → урок → готово |
| `src/hooks/useListenLesson.ts` | проигрывание: один плеер `expo-audio`, `expo-speech`, паузы, фон и экран блокировки |
| `src/utils/listen/script.ts` | сценарий урока (шаги) и длина паузы «повтори» |
| `src/utils/listen/words.ts` | какие слова: изучаемые (слова дня → начатые → текущий этап) или выученные |
| `src/content/audio/zhAudio.ts` | манифест озвучки (генерируется) |
| `scripts/tts/` | выгрузка слов и генерация озвучки |

## Фон

- `app.config.js`: плагин `expo-audio`, `enableBackgroundPlayback: true`, микрофон выключен.
  Нужна новая сборка (dev / preview) — в старой нет нативного модуля.
- На время урока: `shouldPlayInBackground`, `interruptionMode: "doNotMix"` и плеер на
  экране блокировки. На Android без экрана блокировки фоновый звук обрывается ~через 3 мин.
- Уход с экрана останавливает урок; выключенный экран — нет.
