# «Слушай и повторяй» — карта кода

Урок на слух, где ничего не нужно нажимать. Звучит китайская фраза, (перевод вслух),
пауза — повтори вслух, фраза ещё раз. Два круга: второй — вперемешку, без перевода.
Вход — «Тренировки».

## Озвучка

Голос телефона через `expo-speech`: китайский — `zh-CN`, перевод — `ru-RU`.
Скорость китайского — ступени 0.6–1 (settingsStore.listenRate), меняется и во время
урока, действует со следующей фразы. Перевод вслух — переключатель
(settingsStore.listenTranslation).

Пробовали заранее сгенерированные файлы (Kokoro, MeloTTS — открытые модели с
подходящими лицензиями): на отдельных словах и коротких фразах они глотают слоги
и добавляют посторонние звуки — для обучения не годится. Голос телефона лучше.

## Сеты

`src/content/listen/sets.ts` — сеты по ситуациям (кафе и доставка, магазин):
иероглифы, пиньинь, перевод. Новый сет — новый объект в `LISTEN_SETS`.

## Код

| Файл | Что внутри |
|---|---|
| `src/app/(tabs)/games/listen.tsx` | экран: сет, перевод, скорость → урок → готово |
| `src/hooks/useListenLesson.ts` | проигрывание: expo-speech, паузы, пауза/продолжить |
| `src/utils/listen/script.ts` | сценарий урока (шаги) и длина паузы «повтори» |
| `src/content/listen/sets.ts` | сеты фраз |

Уход с экрана останавливает урок.
