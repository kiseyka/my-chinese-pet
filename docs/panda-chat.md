# Чат с пандой

Пользователь пишет панде по-русски, по-китайски или пиньинем. Панда отвечает 1–2 короткими
фразами по-китайски — в основном словами, которые пользователь уже учит, на тему текущего
этапа пути — с пиньинем и переводом. Панда — друг, который учится вместе, а не учитель.
Вход — круглая кнопка с облачком в шапке экрана панды.

## Как устроено

```
приложение (chat.tsx) ──POST──▶ Cloudflare Worker (server/panda-chat) ──▶ модель Workers AI
```

- Ключей в приложении нет: Worker вызывает модель через привязку `AI`.
- Модель — `@cf/qwen/qwen3-30b-a3b-fp8` (лучше всех из дешёвых знает китайский).
  Меняется одной строкой `MODEL` в `server/panda-chat/src/index.ts`.
- Бесплатно: 10 000 «нейронов» в сутки на аккаунт Cloudflare, сброс в 00:00 UTC.
  Одно сообщение — около 10–20 нейронов, то есть порядка 500+ сообщений в сутки на всех.
  Без карты сверх лимита Cloudflare просто отказывает — панда говорит «приходи завтра».
- Лимит на телефоне: 20 сообщений в день (`DAILY_CHAT_LIMIT` в `pandaChatStore`).
  Засчитываются только сообщения, на которые панда ответила.

## Что уходит на сервер

Последние 8 сообщений, до 150 иероглифов слов с хотя бы одной точкой (перевод или письмо)
и текущий этап пути (название + слова). Имя, прогресс и прочее — нет.
Перед релизом: строчка об этом в политике конфиденциальности и кнопка «пожаловаться на ответ»
(требование Google Play для приложений с ИИ-ответами).

## Код

| Файл | Что внутри |
|---|---|
| `server/panda-chat/src/index.ts` | Worker: проверка запроса, промпт панды, разбор ответа модели |
| `server/panda-chat/wrangler.jsonc` | настройки Worker (имя, привязка AI) |
| `src/utils/panda/chatApi.ts` | запрос к серверу и причины ошибок |
| `src/utils/panda/chatContext.ts` | какие слова и этап отправить |
| `src/store/pandaChatStore.ts` | история (последние 60) и дневной лимит |
| `src/app/(tabs)/chat.tsx` | экран чата |

## Настройка (один раз)

1. Аккаунт на cloudflare.com, `npx wrangler login`.
2. `cd server/panda-chat && npm install && npx wrangler deploy` — в конце адрес вида
   `https://panda-chat.<имя>.workers.dev`.
3. В корне проекта файл `.env.local`: `EXPO_PUBLIC_PANDA_CHAT_URL=<адрес>`,
   затем `npx expo start --dev-client --clear`.

После правок сервера — снова `npx wrangler deploy`. Логи в реальном времени — `npx wrangler tail`.

## Известные слабые места

- Пиньинь и перевод пишет модель — иногда ошибается в тонах.
- Модель может взять слово, которого пользователь ещё не знает.
- Адрес сервера виден в APK: кто его достанет, может потратить дневную квоту (но не деньги).
