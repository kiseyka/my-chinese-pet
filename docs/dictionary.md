# Словарь — карта кода

Все слова приложения в одном месте. Деление то же, что у пути: раздел HSK → темы
(этапы пути). Слова без уровня HSK — раздел «Другие слова».

| Файл | Что внутри |
|---|---|
| `src/app/(tabs)/vocabulary.tsx` | экран: поиск, чипсы «Избранное» / HSK / «Другие слова», темы с сеткой слов (точки перевода и письма) |
| `src/utils/dictionary.ts` | разделы, группы раздела (этапы пути), этап, где лежит слово |
| `src/components/dictionary/DictionaryWordSheet.tsx` | панель слова: точки навыков, «Избранное», место на пути и «Показать», наборы |

Сетка слов — общая с экраном этапа (`components/path/PathWordGrid.tsx`).

Дальше: тренировки из словаря (тема, набор, «Повторение» → выбор режима),
«Мои наборы» и одно общее «Повторение» внутри словаря, затем убрать экраны
«Карточки» и «Написание».
