# Экзамены — карта кода

Два экзамена, правила одинаковые:
- слово попадает на экзамен навыка с 3 точками этого навыка, через сутки после третьей точки
  (слова, у которых 3 точки были раньше, чем появился экзамен, готовы сразу);
- сдал — слово отмечено сданным («✓ экзамен» в панели слова);
- первый провал — пересдача через сутки; второй подряд — минус одна точка навыка,
  экзамен ждёт, пока точку снова заработают.

| Файл | Что внутри |
|---|---|
| `src/store/wordProgressStore.ts` | `readingExams`, `writingExams`; `recordExamResult` (общие правила), `getWritingExamStatus` / `getWritingExamQueue` с параметром `skill` |
| `src/hooks/useExamQueue.ts` | очередь навыка: готовые и «скоро» |
| `src/components/dictionary/ExamHubSheet.tsx` | панель «Экзамен» в «Словаре»: по переводу и по письму |
| `src/app/(tabs)/games/reading-exam.tsx` | экзамен по переводу: перевод → выбрать иероглиф из 4 похожих, одна попытка, итоги |
| `src/hooks/useReadingExam.ts` | ход экзамена по переводу, запись итогов, награда |
| `src/utils/readingExam.ts` | подбор похожих вариантов: общий ключ и части, близкое число черт; у слов — общий иероглиф |
| `src/app/(tabs)/games/writing/exam.tsx` | экзамен по письму (см. `docs/writing.md`) |
